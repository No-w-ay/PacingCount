# PacingCount ⏱️💙

> Mesurer son pacing, en douceur. Application web légère conçue pour équilibrer les temps d'activité et de repos (EM/SFC, Long Covid).

## 🔗 Liens utiles
- **Site de présentation (Landing Page) :** [https://home.pacingcount.pages.dev](https://home.pacingcount.pages.dev)
- **Application (PWA) :** [https://pacingcount.pages.dev](https://pacingcount.pages.dev)

## ✨ Fonctionnalités
- **Simple :** Un seul bouton à presser lors du changement d'activité. Calculs et graphiques automatiques pour visualiser ses journées.
- **Personnalisable :** Les types de périodes peuvent être personnalisés.
- **Respect vie privée :** Vos données restent sur votre téléphone.
- **Multilingue :** Disponible en Français (FR), Anglais (EN) et Néerlandais (NL).

## 🛠️ Stack Technique
- **Hébergement :** Cloudflare Pages (déploiement continu via GitHub).
- **Technologies :** HTML5, CSS3, JavaScript natif (Vanilla JS), Progressive Web App (PWA).
