# Historique des versions

Cet historique recense les versions distinctes publiées sur `main` lors d'une fusion depuis `dev`, de la plus récente à la plus ancienne. Les dates sont celles de fusion des pull requests. Les versions intermédiaires présentes uniquement dans l'historique de `dev`, ainsi que les fusions sans changement de version de l'application, ne sont pas listées.

Les descriptions proviennent en priorité des messages de mise à jour de `messages.json`. Quand ceux-ci sont génériques ou absents, le titre et les changements de la pull request servent de complément.
