# Règles de travail

- Avant toute modification, indique le périmètre et les fichiers concernés; attends mon accord explicite avant d'éditer.
- N'effectue aucune action qui change l'état du dépôt ou du serveur — commit, push, changement de branche, PR, tag, release ou réglage GitHub — sans accord explicite.
- L'autorisation d'une tâche vaut uniquement pour le périmètre annoncé; elle n'autorise pas à publier ou à modifier d'autres éléments.
- Préserve mes changements préexistants. Fais des changements ciblés et vérifie le diff avant de terminer.
- Après une modification autorisée, indique les fichiers changés, les vérifications effectuées et les éventuelles limites.
- Si le besoin, le comportement attendu ou le risque d'une action n'est pas clair, arrête-toi et demande-moi.
